# 🎓 BBD Campus Navigator

A smart web-based campus navigation system developed for **Babu Banarasi Das University (BBDU)** to help students quickly find their classroom based on their timetable.

---

## 📖 About The Project

BBD Campus Navigator is a responsive web application that allows students to search for their current classroom by entering their **Name** and **Mobile Number**.

The system verifies the student, identifies the student's section, checks today's timetable, and displays the current class along with complete classroom information.

---

## ✨ Features

- 🔍 Student Verification
- 📅 Automatic Day Detection
- ⏰ Current Time Detection
- 📚 Current Subject Detection
- 🧑‍🏫 Faculty Information
- 🚪 Classroom Number
- 🏢 Floor Information
- 🧭 Wing Information
- 📢 Upcoming Class Detection
- 🍽 Lunch Break Detection
- 🎉 Holiday Detection
- ✅ No Classes Today
- 🌙 Today's Classes are Over

## 🚀 How It Works

1. Enter Student Name.
2. Enter Mobile Number.
3. Click **Find My Class**.
4. Student details are verified.
5. Current day and time are detected automatically.
6. The system finds the student's current class.
7. Room details are mapped from the classroom database.
8. The following information is displayed:

- Current Subject
- Floor
- Wing
- Room Number
- Faculty Name
